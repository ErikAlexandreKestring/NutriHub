# Nutri-Hub

Plataforma SaaS multi-tenant para nutricionistas. Cada nutricionista tem o próprio consultório isolado, com cadastro de pacientes, planos alimentares com a tabela TACO e agenda. O paciente usa um app instalável (PWA) para ver o plano do dia, marcar as refeições feitas, agendar consultas e registrar dificuldades.
